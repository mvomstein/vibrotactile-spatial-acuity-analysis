# Forschungssoftware

Forschungssoftware zur Dissertation *Routing information through touch*
(Max vom Stein, Bergische Universität Wuppertal).

Der im Rahmen dieser Dissertation entwickelte Quellcode steht der Prüfungskommission vorab als
passwortgeschütztes Archiv zur Verfügung: **Releases → v1.0-dissertation-rc1 → .zip-Datei**.
Das Archiv ist mit AES-256 verschlüsselt; zum Öffnen wird 7-Zip (Windows) bzw. Keka (macOS) benötigt.

**Passwort:** Das erste Wort des Untertitels der Dissertation, ausschließlich in Kleinbuchstaben.

Mit der Veröffentlichung der Dissertation werden Quellcode und nicht bereits publizierte Datensätze
öffentlich zugänglich gemacht.
